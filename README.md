# 凯隆餐室 · 宴席菜单（优化版）

在线菜单：https://gugu517.github.io/kailong-menu/

仓库：https://github.com/gugu517/kailong-menu

访问密码：`88888888`。

本项目为本地宴席菜单工具，使用原生 HTML、CSS、JavaScript。没有后端、数据库、安装依赖或构建步骤；应用资源均随项目提供，不依赖 CDN。

## 打开项目

解压后双击 `index.html`。原入口名 `订餐系统.html` 也保留了相同页面。

需要通过固定地址使用时，在此目录执行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8000/`。请始终使用同一个入口和地址；不同浏览器、协议、端口以及本地文件入口可能使用不同的存储空间。

## 已实现

- 73 道菜品、5 个分类、3 套宴席搭配。
- 菜名、食材、旧菜名与喜庆别名搜索；仅看已选筛选。
- 选用套餐时选择替换或追加；单道换菜；显示与原套餐的差异。
- 选菜、本地菜品修改、餐厅设置及宴席信息自动保存。
- 图文、简洁、喜庆三种菜单；可选喜庆别名；A4 打印及浏览器另存 PDF。
- 本地菜品新增、编辑、删除，照片上传压缩，待确认资料筛选。
- 菜单 JSON 导入导出，完整备份迁移与恢复默认资料。
- 存储异常提示、旧版菜单恢复、导入校验、文本转义与键盘操作支持。
- 桌面已选菜单侧栏、手机底部操作栏及响应式布局。

## 修改与备份

日常修改请使用页面的“菜品管理”和“餐厅设置”，修改只保存在当前浏览器。将整个文件夹复制到别处不会自动带走这些修改，请导出“完整备份”并在另一台设备导入。

菜单 JSON 仅保存已选菜品 ID 和宴席信息，自定义菜品和照片需使用完整备份迁移。完整备份包含上传照片的数据；项目自带照片仍随项目文件夹提供，迁移时请保留整个文件夹。

需要改变默认资料时可编辑 `js/dishes.js`。已有本地保存资料优先于默认资料；请先备份，再恢复默认资料以加载新默认数据。

## 价格与内容

套餐价格沿用原项目的 1688、1888、2588 元。修改搭配后只显示原套餐参考，不自动计算差价。实际价格请由餐厅确认。

八处明显错配或不同版本共用照片暂不展示；原照片仍保留在 `sourceImage` 和图片文件中。十二项待确认事项见 `docs/图片待补清单.md`。本次未生成替代菜品照片，也未将无法确定的食材称谓强行改名。
