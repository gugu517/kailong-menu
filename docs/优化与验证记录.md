## 验证边界与使用注意

- 没有连接实体打印机；实体打印须以浏览器打印预览和打印机纸张设置为准。
- 自动浏览器工具仅允许 HTTP/HTTPS，因此没有通过该工具测试 `file://` 入口；应用采用普通本地脚本和相对资源，支持直接打开，HTTP 入口已实测。
- 本次没有跨设备、多浏览器或实际移动硬件测试；手机检查采用浏览器视口。
- 菜品食材、真实做法、套餐售价及待确认照片仍需餐厅确认。
- 页面修改保存在浏览器，不会自动改写项目的默认 JavaScript 文件。自定义照片多时可能超过本地存储额度；页面提示后应立即导出完整备份。
- 没有引入真实下单、支付、联网同步或服务端管理，菜单内容用于餐厅沟通与确认。
